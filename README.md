# Ninja Ping Support

Ninja Ping公式サポートページ。日本語・英語を併記した静的HTML/CSSサイトです。

- 開発者・運営者: komaru.dev
- 問い合わせ: ninjaping.app@outlook.jp
- プライバシーポリシー: https://komaru-dev.github.io/ninjaping-privacy/

## ファイル

- `index.html`: 日英のアプリ紹介、問い合わせ、不具合報告、ポリシーリンク
- `styles.css`: ローカルのレスポンシブスタイル
- `.nojekyll`: GitHub PagesでJekyll処理を無効化
- `README.md`: この説明

## ローカル確認

`index.html`をブラウザで開いて確認できます。ビルドや依存インストールは不要です。
JavaScript、外部フォント、CDN、アクセス解析、トラッキングは使用しません。
