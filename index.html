不具合報告 Bug Reports

日本語

不具合をご報告いただく際は、可能な範囲で以下の情報をお知らせください。

  • アプリのバージョン
  • iOSのバージョン
  • 発生した問題
  • 問題が発生するまでの操作手順

スクリーンショットを添付する場合は、個人情報が含まれていないかご確認ください。

English

When reporting a problem, please include the following information if possible:

  • App version
  • iOS version
  • Description of the issue
  • Steps to reproduce the issue

Before attaching screenshots, please remove or hide any personal information.
